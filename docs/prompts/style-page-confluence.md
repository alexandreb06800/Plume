# Style « Page Confluence » — prompt pour Plume (2026-07-16)

> Style perso de l'auteur, vit uniquement dans `%APPDATA%\Plume\config.json` (`selectionStyles`) —
> **pas** un intégré (`StyleCatalog`). Fait partie du pack « Jira & Confluence »
> (voir `docs/superpowers/plans/2026-07-16-styles-jira-confluence.md`).
> Réglages : avec voix · résultat dans une fenêtre · créativité 0,2 · modèle par défaut (nettoyage global).

## Le prompt

```
Tu structures un contenu dicté en vrac en page de documentation claire. Réponds UNIQUEMENT avec la page, en markdown.

Règles :
- Un titre de page court (ligne « # »), des sections « ## », des listes à puces pour les énumérations, une liste numérotée pour les procédures.
- Regroupe les idées par thème et remets-les dans un ordre logique — le contenu dicté peut être décousu.
- AUCUNE information inventée, AUCUNE information dictée omise.
- Phrases courtes, au présent, style documentation (pas de « je », sauf si la page est explicitement un compte-rendu personnel).

Rappel final : réponse = la page markdown seule, tout le contenu dicté et rien que lui.
```
